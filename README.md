# ValTrans 公共词库

《无畏契约》外服实时语音翻译软件 ValTrans 的**公共游戏语音词库**。

## 这是什么

玩家在游戏里遇到翻译不准时，可以点「提交误报」。同一个说法被**多个不同玩家**
报成同一句译文后，才会进入这个仓库。

因此这里面的每一条都是**社区共识**，不是某一个人的偏好。

## 为什么不自建服务器

用户决定开源分发，所以词库直接放 Git 仓库：

- 零运营成本、永久可用
- 每次改动**有 git 历史、可追溯、可回滚**
- 任何人可 review、可提 PR，天然有人把关
- 不经过任何人的服务器 = 没有单点作恶/跑路风险

## 隐私

**只上传用户主动提交的那一条文本。** 不收集：完整对局记录、音频、
API Key、设备信息、时间戳、用户身份。

`reporters` 字段是**去重后的上报人数**，不记录是谁 —— 众包要的是共识度，
不是身份。

## 数据格式

`lexicon.json`：

```json
{
  "version": 1,
  "updated": "2026-10-03",
  "terms": [
    {
      "src": "they are setting up on a",
      "dst": "他们在A点架枪",
      "lang": "en",
      "reporters": 5
    }
  ]
}
```

字段说明：

| 字段 | 含义 |
|---|---|
| `src` | 队友原话（检测到的源文本） |
| `dst` | 社区共识译文 |
| `lang` | 源语言（en / ja / ko） |
| `reporters` | **去重后**的上报人数 |

## 收录规则

1. **同一说法 ≥ 3 个不同上报者**才收录（`ADOPT_MIN_DISTINCT_REPORTS`）
2. **说法有分歧时一条都不收** —— 游戏黑话有地域差异
   （「大残」/「残血」/「快没血了」），硬投票会把少数但正确的说法覆盖掉。
   有分歧的条目走人工 review。
3. 改动请走 PR，附上你看到的原话和为什么这么译。

## 相关

- 软件本体：`ValTrans`（本仓库只放词库，不放源码）
- 词库格式与客户端同步逻辑：`src/services/community.py`

## 授权

本仓库**两种授权并存**，按文件区分：

| 内容 | 授权 | 文件 |
|---|---|---|
| 词库数据（`lexicon.json` 及后续所有词条） | **CC0 1.0**（公有领域奉献） | [`LICENSE-LEXICON`](LICENSE-LEXICON) |
| 仓库自身的说明文档与脚本 | **MIT** | [`LICENSE`](LICENSE) |

选 CC0 是因为词条是**多名玩家上报形成的共识**，让任何人都能拿去改、
拿去商用、拿去嵌进自己的翻译工具，而不用担心「要署名」或「要沿用同一协议」。
CC0 是最没有附加条件的那一种。

## `latest.json` 是什么

客户端的「检查更新」在大陆网络下常常连不上 GitHub，会退而读本仓库里的
`latest.json`（走 jsDelivr CDN）作为兜底。它有四个字段：

```json
{
  "version": "0.2.22",
  "build": "20261008-1",
  "url": "https://github.com/cingzz/ValTrans/releases/tag/v0.2.22",
  "notes": "一句话说明"
}
```

**每次发版必须手工改这里的 `version`、`build` 和 `url`。**

`build` 是**构建标识**，形如 `20261008-1`：只要重新打包就换一个，
哪怕版本号不动。客户端在版本号相同时会比它 —— 不同就提示
「同版本有更新构建（含修复）」，并把下载入口摆出来。

**为什么需要它**：只比版本号的话，同一版本号下重打二进制，
老用户手上的旧构建会被判定成「已是最新」，而且永远等不到提示。
本项目 v0.2.22 就因此出过事 —— 传上去的产物早于代码修改，
可产物里的版本号已经是 0.2.22，于是「已是最新」骗过了所有人。

`build` 的值必须与 `ValTrans/src/version.py` 里的 `BUILD` **完全一致**：
一边编译进二进制，一边发布在这里。打包后要回读产物里的 `BUILD`
与本文件比对，不一致就说明发布链断了。

漏改 `version` 或 `url` 的后果：兜底通道报「已是最新」，
用户收不到提醒 —— 这是个不会自己报警的坑，
所以放在这里写明。
